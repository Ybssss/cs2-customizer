# CI-only dependency (GitHub Actions windows-latest).
# What CI needs = the runtime dependencies + the test runner.
#
# WHY THE RUNTIME PACKAGES ARE NOT REPEATED HERE
#   This file used to list every runtime package a second time (flask / pygame /
#   keyboard / pynput / pywin32 / pypinyin / numpy / sounddevice / soundfile /
#   PyYAML) so that CI would install them. That is how "CI installs it, packaging
#   does not" happened: CI stayed green while the shipped artifact was missing
#   flask and would not start (Release v2.3.1). Two copies of one list is two
#   places to rot, and they rot in opposite directions.
#   The runtime list now lives in requirements.txt only.
#
# WHY THE COMMENTS HERE ARE ASCII
#   pip decodes a requirements file with the MACHINE'S LOCALE CODEC. On a Chinese
#   Windows box that is GBK, and UTF-8 Chinese in the comments is not always
#   decodable - pip raises UnicodeDecodeError before it even starts resolving.
#   A requirements file is read by pip on arbitrary machines, so keep it ASCII.
-r requirements_qt.txt
-r requirements.txt

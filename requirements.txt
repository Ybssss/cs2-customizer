# `requirements_qt.txt` 里逐字写着：

#  1. 按 README 装依赖再 `python main_widget.py`：`ModuleNotFoundError: flask`。
#     `gsi_server.py:7` 是**顶层** `from flask import Flask, …`，而 GSI 接收端由主窗口
#     启动 —— 缺 flask 就等于程序起不来。开发机上碰巧全局装过 flask，所以从没暴露。
#  2. 打包产物缺 flask：2026-09-28 第一次成功发布的 v2.3.1，双击即崩
#     `Failed to execute script 'main_widget' … No module named 'flask'`。
#     打包流水线装的是 requirements_qt.txt + requirements-build.txt，于是**冻进 exe 的
#     只有 Qt 那一半**。
#
# 为什么 CI 一直是绿的：requirements-ci.txt 当时把下面这些包**又抄了一遍**，
# CI 装得到，打包装不到。同一份依赖写两遍，就一定有一处会腐烂——这次烂在打包那一侧。
# 现在 requirements-ci.txt 改为 `-r requirements.txt`，**只留一份**。
#
# 版本下限与原 requirements-ci.txt 逐条一致，**没有改动任何一个约束**。
